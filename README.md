## ​ Features

| Feature               | Description |
|------------------------|-------------|
| **Scaffold Setup**     | React + Vite with ESLint and Prettier—ideal foundation |
| **Fast Dev Workflow**  | Vite-powered development with hot module replacement |
| **Minimal Starter**    | Clean codebase to build features like add/edit/delete todos |
| **Expandable Design**  | Ready to integrate functionality like localStorage, filters, or mobile responsiveness |
| **Clean Project Layout** | Maintains solid structure for easy scalability |

## ​ Getting Started

```bash
# 1) Clone the repository
git clone https://github.com/miladmo68/Todo-List.git
cd Todo-List

# 2) Install dependencies
npm install

# 3) Run development server
npm run dev

# 4) Build for production
npm run build
